Privacy Policy for BetterFind

Effective date: July 17, 2026

BetterFind is a Chrome extension that provides a better page search/find experience than Chrome's native find feature.

Information Collection

BetterFind does not collect, capture, track, transmit, or sell personal data.

Settings

BetterFind allows users to save custom settings for the extension experience. These settings are used only for extension functionality and are not collected as analytics or user data.

Contact

If you have questions about this privacy policy, please contact the extension publisher.
